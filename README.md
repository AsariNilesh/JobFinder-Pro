# JobFinder Pro

A responsive job search web application built using HTML, CSS and JavaScript.

## Features

- Search jobs by keyword and location
- Filter jobs by category and job type
- View job details
- Save jobs using LocalStorage
- Saved Jobs page
- Dashboard
- Responsive design

## Technologies Used

- HTML
- CSS
- JavaScript
- JSON
- LocalStorage

## How to Run

1. Clone or download this repository
2. Open it in VS Code
3. Run using Live Server
4. Open `index.html`
