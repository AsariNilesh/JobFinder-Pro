# 💼 JobFinder-Pro - Job Search Web Application

A responsive job search web application built with HTML, CSS, and vanilla JavaScript.

---

## ✨ Features

- 🔍 Search Jobs — Filter by title, skill, company, or location
- 📋 Featured Jobs — Latest job openings
- 🏢 Company Details — Name, location, salary
- 📄 Job Detail View — Click "View Details" for full info
- 📱 Fully Responsive — Mobile, tablet, desktop
- 🎨 Clean UI — Modern design

---

## 🛠️ Tech Stack

| Technology | Purpose |
|------------|---------|
| HTML5 | Structure |
| CSS3 | Styling, Grid, Flexbox |
| JavaScript | Search, DOM manipulation |

## 🎯 Key Functionality

### 🔍 Search Feature
- Filter jobs by title, skill, company, or location
- Real-time results as you type

### 📄 Job Details
- Click "View Details" on any job card
- Full job description, requirements, and company info

### ❤️ Saved Jobs
- Bookmark jobs for later
- Stored in `localStorage`

### 📊 Dashboard
- View saved jobs count
- Recent activity
- Quick links

### 📱 Responsive Design
- Desktop: Multi-column layout
- Tablet: Adjusted grid
- Mobile: Single column
